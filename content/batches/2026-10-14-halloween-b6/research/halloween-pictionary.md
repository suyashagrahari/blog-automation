## Phase 3: sources (all fetched)
1. **Mosovsky 2018**, J Microbiol Biol Educ 19(3), ASM, CC BY-NC-ND, full text via Europe PMC PMC6289827. Teams draw at the same time, Pictionary-style. Drawer rules: "no talking, no sounds, no gestures, no numbers/letters". Takes 15-45 min. Survey of 64 students over 3 semesters: 100% found it fun, 98% would recommend it, 94% rated it effective or very effective. FULL TEXT READ.
2. **Hawkins, Sano, Goodman & Fan 2023**, Nature Communications, CC BY, full text via Europe PMC PMC10110538. 138 participants formed 69 pairs and played a Pictionary-style reference game with a 30-second drawing limit. Strokes per drawing fell steadily over repetitions. Drawings kept visually diagnostic features and did not drift to arbitrary symbols. Replication: 130 participants. FULL TEXT READ.
3. **Roberts & Wammes 2021**, Psychonomic Bulletin & Review 28(1):259-267, Springer, epub 16 Sep 2020. Drawing beat writing for memory across concrete and abstract words, and the benefit was slightly larger for concrete words. ABSTRACT ONLY via PubMed 32939630 (Springer's page bot-walled; OpenAlex marks it bronze OA).
4. **Bainbridge, Chamberlain, Wammes & Fan 2024**, Memory & Cognition special-issue editorial, Springer, green OA author copy at research.gold.ac.uk. It summarises Ovalle-Fresa & Martarelli: drawing improves associative memory in younger adults, but only item memory in older adults. It also notes drawing helped recall in hippocampal-damage patients. FULL TEXT READ.
5. **USPTO** trademark record, read through the official tmsearch API on 2026-10-14. TSDR returned 429, so the API was used instead. Findings:
   - PICTIONARY, Reg. 1,392,492 (serial 73529303), filed 28 Mar 1985, registered 6 May 1986, class 28 "equipment sold as a unit for playing a board game". First use 16 Feb 1985. Original registrant Robert S. Angel, Seattle. Last listed owner Pictionary Incorporated (Nevada), 333 Continental Boulevard, El Segundo CA. Status "registered and renewed".
   - Mattel, Inc. at the same street address registered PICTIONARY PIC-TATO (Reg. 8,189,216, 24 Mar 2026).
   - Pictionary Inc. also has an application (serial 98883442, filed 3 Dec 2024) covering clothing including "Halloween costumes".

**Brief/prompt claim corrected:** the prompt said "Pictionary is a registered trademark (Mattel)". The USPTO record names **Pictionary Incorporated** as owner of the core board-game mark. That company is at the same El Segundo street address as Mattel, Inc., and Mattel itself holds the 2026 PIC-TATO registration. The post says exactly that, and does not call the mark "Mattel's" or Pictionary Inc. a "subsidiary". Neither is stated in the record.
