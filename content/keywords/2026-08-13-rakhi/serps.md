## Phase 3 — answer-engine stability

Three question-shaped queries were re-run. **All three returned identical domain
sets on both runs**, so nothing was discarded as retrieval noise and every cited
domain is high-confidence.

Cited across both runs: `igp.com`, `floweraura.com`, `rakhibazaar.com`,
`adobe.com`, `nestasia.in`, `gladful.in`, `bablarakhi.com`, `tohfatales.com`.

**The finding that matters:** the answer-engine set is *entirely* gifting-commerce
blogs. No tool page is cited for any question-shaped rakhi query. A tool page can be
cited here — the citation set has no incumbent tool to displace.

**Honest limit:** this is `WebSearch`'s synthesised answer, **not** ChatGPT,
Perplexity or Gemini. Those cannot be queried from here. To get real citation data,
run the 10 Axis-8 queries in each engine by hand and paste the cited domains back.
