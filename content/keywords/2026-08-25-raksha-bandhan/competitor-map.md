## URL architecture worth copying

**fnp.com** and **floweraura.com** both run the same pattern and it is the right one:

```
/quotes/raksha-bandhan/            ← hub
/quotes/raksha-bandhan/hindi       ← language spoke
/quotes/raksha-bandhan/punjabi
/quotes/raksha-bandhan/for-younger-brother   ← relationship spoke
```

One hub, one spoke per language and per relationship, all internally linked. Your 39
rakhi posts are **flat** — no hub, no spoke structure, and four of them collide with
each other. A `/blog/raksha-bandhan-wishes/` hub linking the language and relationship
posts would cost one page and is probably worth more than any single new post on the
shortlist.

## The finding that decides the run

**English and Hindi SERPs contain real brands. Regional-language SERPs contain nobody.**

| Query | Strong incumbents |
|---|---|
| wishes in hindi | IGP (2026), FNP, FlowerAura |
| greetings online free / wishes maker | Canva, Adobe, PosterMyWall |
| kab hai / muhurat / 2027 date | Wikipedia, DrikPanchang, Brut, IBTimes, panchang sites |
| **wishes in gujarati** | **none** |
| **wishes in kannada** | **none** — a news tag page, a Pinterest board, a Weebly site |
| **wishes in punjabi** | FNP only — Pinterest is at position 1 |

That is the whole strategy for this seed: **go where the brands aren't, which is the
regional languages, and build the hub FNP has and you don't.**

## Google-only vs answer-engine-only

Not separable this run. The available search tool returns one result set; no
synthesised-answer citation layer was observable, so **no answer-engine claim is made
here.** Phase 5 was not run as a distinct pass, and this run should not be read as
containing GEO/AEO evidence.

## What none of them cover

- **Send-a-link intent.** Every incumbent gives you text to copy or an image to
  download. Only `rayxis.space` and `untumble.com` give the searcher a *page to send*,
  and both are tiny. This is the gap and it is the product.
- **Regional languages beyond Hindi/Marathi/Gujarati** at any quality. Kannada,
  Punjabi, Telugu, Odia, Assamese are served by tag pages and Weebly sites.
- **A language hub.** Nobody in the weak tier has one; the two brands that do (FNP,
  FlowerAura) skip the small languages entirely.
